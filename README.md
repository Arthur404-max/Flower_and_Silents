# ЦветоТишина

Готовый демонстрационный интернет-магазин цветов: витрина, каталог, корзина, оформление заказа, демо-оплата, личный статус заказа и панель администратора.

> **Это демо-версия.** Товары, цены, условия доставки и изображения приведены для примера. Оплата ничего не списывает, сообщения не отправляются, реальные адрес и телефон магазина не указаны. Перед открытием для покупателей замените демо-данные и подключите настоящие сервисы.

## Что уже работает

- поиск, категории, сортировка и карточки товаров;
- корзина с сохранением в браузере;
- пересчёт цен и остатков на сервере;
- самовывоз и доставка с демо-тарифом;
- создание заказа без дублей при повторной отправке;
- демо-оплата и страница статуса заказа по защищённой ссылке;
- вход администратора, товары, категории, изображения и статусы заказов;
- кэширование каталога, фоновая обработка событий и мониторинг.

Демонстрационные условия: доставка — **2 900 ₽**, бесплатно при заказе от **5 000 ₽**. Самовывоз бесплатный. Неоплаченный заказ автоматически отменяется через 30 минут.

## Самый простой запуск — Docker

Нужен Docker Desktop с включённой поддержкой Linux-контейнеров.

1. Скопируйте `.env.example` в `.env`.
2. В `.env` замените пароли, `JWT_SECRET`, почту и пароль администратора. Не публикуйте этот файл.
3. Откройте терминал в папке проекта и выполните:

```bash
docker compose up --build -d --wait
```

4. Откройте магазин: <http://localhost:8080>.
5. Панель администратора: <http://localhost:8080/admin>. Войдите с `ADMIN_EMAIL` и `ADMIN_PASSWORD` из `.env`.
6. Мониторинг: Grafana <http://localhost:3002>, пароль `GRAFANA_ADMIN_PASSWORD`; Prometheus <http://localhost:9090>.

Остановить:

```bash
docker compose down
```

Данные при этом сохраняются. Команда `docker compose down -v` **удаляет базу, заказы, изображения и настройки** — используйте её только для полного сброса демо.

## Запуск без Docker

Нужны Node.js 22.12 или новее, PostgreSQL 16+ и Redis 7+.

1. Создайте базу `cvetotishina` и пользователя PostgreSQL.
2. Скопируйте `.env.example` в `.env`.
3. Укажите в `.env` адреса локальных сервисов, например:

```dotenv
DATABASE_URL=postgresql://cvetotishina:ВАШ_ПАРОЛЬ@127.0.0.1:5432/cvetotishina?schema=public
REDIS_URL=redis://127.0.0.1:6379
WEB_ORIGIN=http://localhost:5173,http://127.0.0.1:5173
API_PORT=3000
VITE_API_PROXY_TARGET=http://localhost:3000
```

Если порт 3000 занят, выберите другой, например `API_PORT=3100`, и укажите `VITE_API_PROXY_TARGET=http://localhost:3100`.

4. Выполните:

```bash
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

5. Откройте <http://localhost:5173>, администратор — <http://localhost:5173/admin>.

При первом seed создаётся демо-каталог и администратор. Повторный seed не перезаписывает изменённые товары и не сбрасывает пароль существующего администратора.

## Как сделать тестовый заказ

1. Выберите букет и добавьте его в корзину.
2. Нажмите «Оформить заказ».
3. Заполните имя, телефон и выберите самовывоз или укажите адрес доставки.
4. Отправьте заказ и подтвердите демо-оплату.
5. Сохраните страницу заказа: ссылка содержит одноразовый токен доступа.
6. В админке откройте заказ и меняйте статусы по порядку: «Принят в работу» → «Собираем букет» → «Передан курьеру» → «Доставлен».

Деньги не списываются. Тестовые уведомления видны только внутри системы и никуда не отправляются.

## Работа администратора

- **Товары:** название, категория, состав, размер, цена в рублях, остаток, изображение, архив и восстановление.
- **Категории:** порядок показа и скрытие категории.
- **Заказы:** поиск по номеру, имени или телефону; состав, история и безопасная смена статуса.
- **Изображения:** загрузка JPG, PNG или WebP до 5 МБ.
- **Пароль:** смените его в разделе администратора после первого входа.

При скрытии товара он исчезает с витрины, но сохраняется в старых заказах. При отмене заказа до передачи курьеру остатки возвращаются автоматически.

## Резервная копия

Для Docker:

```bash
docker compose exec -T postgres pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB" > cvetotishina-backup.sql
```

Также сохраняйте папку `uploads`: в Docker она хранится в томе `uploads`, при локальном запуске — в папке проекта `uploads`.

Перед восстановлением остановите API и worker, восстановите базу и изображения, затем запустите их снова.

## Перед настоящим открытием

- заменить демо-каталог, цены, остатки и условия доставки;
- добавить реальные контакты, реквизиты и юридические страницы;
- подключить ЮKassa/СБП или другой платёжный провайдер;
- подключить доставку и настоящие SMS/email/Push-уведомления;
- включить HTTPS и `COOKIE_SECURE=true`;
- настроить регулярные резервные копии и обновления;
- провести нагрузочное тестирование на целевом сервере.

Docker Compose удобен для одного сервера и демонстрации балансировки, но не заменяет отказоустойчивую инфраструктуру с отдельными копиями PostgreSQL и Redis.
